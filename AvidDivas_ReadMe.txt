You are Rock, one half of the guitar duo Rock & Ghoul, Rock & Ghoul are about to perform at Jam Out SG.When Ghoul steps away to go to the restroom, malicious spirits appear to attack Rock (player character). Using her guitar’s newly-found powers, Rock defeats them and makes her way to the stage, looking for Ghoul.

This game is made with a custom engine that allows F1 for IMGUI toggling.

Engine Info
* Displays FPS and frame timing
* Displays per-system performance with progress bars

Collision + Prefab
* Provides toggle for collider and velocity vector debug overlays.
* Includes scene save/load buttons
* Prefab dropdown: lists prefab JSON files from folder and spawns selected prefabs into scene.

Hierarchy + Editor
Hierarchy: Lists all tagged entities with type
Editor: (displays components of entity, allows live editing of the following)
* Transform (position and rotation)
* Sprite (texture, scale, rotation)
* Shape (type, dimensions, colour)
* Physics (AABB size, circle radius, collision toggle)
* Tag (entity type)
* Provides clone and delete buttons. Protected entities cannot be deleted.
